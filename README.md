# Интернет-магазин на Django

Учебный проект интернет-магазина, разрабатываемый в рамках курса по Django.

## Описание проекта

Проект представляет собой основу для интернет-магазина с реализованным каталогом товаров и страницей контактов. В дальнейшем функциональность будет расширяться.

## Функциональность

- Главная страница с приветствием
- Страница контактов с формой обратной связи
- Адаптивная верстка с использованием Bootstrap 5

## Технологии

- Python 3.12
- Django
- Bootstrap 5
- HTML/CSS

## Установка и запуск
Проект использует Poetry для управления зависимостями. Все зависимости указаны в pyproject.toml. Для установки выполните:
```
pip install poetry
poetry install
```
